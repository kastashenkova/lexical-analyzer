# Лабораторна робота № 1. Лексичний аналізатор

Проєкт реалізує лексичний аналізатор для фрагмента мови програмування, написаний мовою Java.

## Архітектура та принцип роботи

Лексер побудований на основі регулярних виразів (`java.util.regex.Pattern` та `Matcher`), що дозволяє ефективно та безпомилково розбивати вхідний текст на лексеми за один прохід, уникаючи проблем із відсутністю пробілів між символами.

### Основні компоненти:

1.  **`LexemeClass.java` (Enum):** зберігає типи лексем (IDENTIFIER, NUMBER, OPERATOR, FUNCTION, KEYWORD, STRING, BOOLEAN, SYMBOL, ERROR, EOF)
2.  **`Token.java`:** об'єктне представлення лексеми (зберігає сам рядок та його тип)
3.  **`Analyzer.java`:** ядро аналізатора
    *   містить єдиний складений регулярний вираз (`TOKEN`), розділений на іменовані групи (WHITESPACE, STRING, WORD, OPERATOR, SYMBOL, ERR)
    *   метод `nextToken()` послідовно знаходить збіги за допомогою `Matcher.find()`
    *   метод `defineClass()` виконує подальшу деталізацію знайдених слів (WORD), перевіряючи, чи є слово ключовим словом (`Set KEYWORDS`), вбудованою функцією (`Set FUNCTIONS`), булевим значенням, числом чи ідентифікатором (через `switch` з pattern matching)
    *   **особливість:** ідентифікатори розпізнаються за умовою завдання — пропускаються лише ті, що складаються з цифр та літер прізвища Асташенкова/Astashenkova (і кирилицею, і латиницею)
4.  **`Main.java`:** містить тестовий код (із правильними конструкціями та навмисними лексичними помилками) та виводить результат у консоль

## Як запустити
Клас `Main.java`.
Програма проаналізує вбудований тестовий рядок і виведе список знайдених токенів у консоль.
